```bash
test "$(gh run view "$RUN" --repo "$REPO" --json workflowName --jq .workflowName)" = 'AERIS next candidate acceptance (no publication)'
test "$(gh api "repos/$REPO/contents/VERSION?ref=$SHA" --jq .content | base64 -d)" = 0.2.0

gh run download "$RUN" --repo "$REPO" --name aeris-next-candidate --dir "$DIR/package"
gh run download "$RUN" --repo "$REPO" --name aeris-next-acceptance --dir "$DIR/integration"
test "$(cat "$DIR/package/revision.txt")" = "$SHA"
test "$(cat "$DIR/integration/revision.txt")" = "$SHA"
test -f "$DIR/integration/workload.json"
test -f "$DIR/integration/recovery.txt"
(cd "$DIR/package" && sha256sum -c SHA256SUMS)

python -m scripts.verify_candidate_bundle "$DIR/package" --expected-revision "$SHA"

gh release create v0.2.0 "$DIR/package/"* --repo "$REPO" --target "$SHA" --draft --title "AERIS v0.2.0 - Expanded Research Release" --notes-file docs/next_research_release_review.md
```
