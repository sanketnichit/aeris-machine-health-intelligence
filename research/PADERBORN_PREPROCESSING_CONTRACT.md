# Conditional Paderborn preprocessing — pre-scoring contract

Two explicit hypotheses, neither established by the archive: (A) vibration samples are uniformly digitized at the publisher's nominal 64 kHz; (B) each stored HostService timestamp is the corresponding sample instant in seconds. Internally consistent one-based XIndex, raster and vector length are required for B. The stored clock may instead describe the exporter, so this is a sensitivity comparison, not a physical correction.

Both paths begin at the first source sample and use identical Kaiser polyphase 3/16 downsampling to 12 kHz, then the first four complete 8192-sample windows, matching the existing MFPT recipe. B first interpolates linearly onto a 64 kHz grid wholly inside the stored range, without extrapolation. It withholds if gaps exceed eight nominal intervals or if effective duration is insufficient. The eight-interval ceiling is a fixed numerical guard against large interpolation gaps, not an instrument specification. A minimum 256 extra source samples beyond the analyzed extent limits endpoint artifacts. No use of labels. A synthetic test confirms uniform-path equivalence; additional fixtures exercise irregular times and invalid geometry. No physical waveform comparisons or diagnostic scores are reported by these tests.

The geometry helper implements standard rolling bearing orders using explicitly provided element count, pitch diameter, element diameter and contact angle; ball order is twice BSF, matching the frozen MFPT rule. No inferred specimen defaults are allowed. A source-reviewed geometry table and declared interpretation of speed and time units are required before a frozen conditional Paderborn scoring protocol. For physical operational advice the independently justified calibration gate still abstains. Differences between hypotheses cannot identify the true clock.
