# MFPT declared bias-budget protocol

Model the indicated speed as reference speed times (1 + systematic relative error + repeatability relative error). Both error components are bounded relative to the same reference speed; these are absolute bounds, not standard deviations or independent random variables. The triangle inequality gives total relative error bound equal to the sum. The admissible reference/indicated scale interval is [1/(1+total), 1/(1-total)]. Unknown systematic error bound produces abstention. No estimate of bias is obtained from fault labels or vibration spectra. Arithmetic is floating-point, not formal interval arithmetic.

Freeze the earlier five indicated-speed errors (-5%, -1%, 0%, +1%, +5%), 17 recordings, preprocessing and thresholds. Evaluate 0.1%, 0.5%, 1% repeatability bounds and 0%, 1%, 5% assumed bias bounds. The synthetic perturbation is treated as fixed bias with zero simulated random noise. This produces 45 scenarios (765 repeated record-scenarios), with deliberately understated as well as adequate bias assumptions. Zero assumed bias is a mathematical control, not a credible default for uncalibrated equipment.

For each scenario reproduce the registered repeatability-only verifier aggregate; compare correct and incorrect accepted, abstentions, withheld correct/incorrect suggestions, newly accepted suggestions (numerical sufficient-test effects), missing-bias acceptance, and actual reference containment separately from whether the assumed systematic bias bound contains the injected bias. No threshold changes, sensor specifications, independent validation or field deployment claims. The missing-bias gate is research-only; the production decision API is unchanged.
