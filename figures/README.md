# Analysis figures

These are a few plots I kept in the repo so the basic EDA is visible without running the whole project again.

## Current figures

- 01_class_balance.svg - shows why the failure class needs more than accuracy.
- 02_failure_rate_by_type.svg - failure rate for each AI4I product type.
- 06_correlation_heatmap.svg - correlations between the main numeric inputs and the failure label.

The threshold scripts also generate calibration and precision-recall plots locally.

The AI4I CSV itself is not committed to the repo.
